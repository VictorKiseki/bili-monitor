# Windows 登录自启与守护

## 在监控台设置

打开「进程」页，在「监控台主进程」的操作区管理 Windows 登录自启。配置后，Windows 登录时会启动监控台。登录自启和立即运行是两项独立设置。账号已绑定时，监控台会按账号状态启动采集和推送任务。

## 从安装目录操作

如果浏览器无法打开监控台，可在安装目录使用 PowerShell 管理本机服务。

```powershell
powershell -File scripts/service.ps1 status
powershell -File scripts/service.ps1 start
powershell -File scripts/service.ps1 stop
powershell -File scripts/service.ps1 install
powershell -File scripts/service.ps1 uninstall
```

status 显示运行状态。start 和 stop 控制当前进程。install 和 uninstall 分别添加和移除登录自启。

## 启动失败时

检查安装目录是否可写，以及监控台端口是否已由其他程序占用。监控台和各任务的错误可从「日志」和「进程」页查看。换机、升级及控制台无法访问时的处理方式见[安装与升级指南](31-发布与交接手册.md)。
