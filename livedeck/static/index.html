这两个开关是什么
播放模式舞台头的「流畅优先 / 低延迟」
  • 流畅优先（默认）：缓冲约 4 秒，不裁剪已缓冲的数据。高码率、60fps 的房间更稳，代价是画面落后直播约 4 秒；每 20 分钟自动软重连一次回收内存。
  • 低延迟：缓冲约 2.5 秒，更贴近直播。网络抖动或高码率房间偶发卡顿时，切回流畅优先。
后台播放窗口最小化 / 切到别的标签页时怎么办
  • 后台暂停（默认）：切走 5 秒后暂停全部画面以省内存，弹幕照收；切回来每隔 0.1 秒逐个自动恢复。
  • 后台续播：最小化也继续拉流解码，适合挂机盯盘或听声音；内存和 CPU 占用会明显更高。
两个选择都只影响这台电脑的这个浏览器（存在 localStorage）。

使用说明

本地运行的多屏监控室：画面由本地服务端把 B 站直播流（HTTP-FLV）转成 WebSocket 喂给播放器，弹幕由本地「浏览器桥」统一转发，所以可以合并、筛选、归档展示。

首次使用：左侧点房间行的「＋」加入舞台 → 画面会自动连上；默认静音，鼠标移到格子上调音量。多路同时播放会占用较多内存（每格一路视频解码），16 路大约 1.5~2 GB，建议 4~9 路。
  1. 1登录：右上角登录，扫码即可；发弹幕需要 bili_jct，扫码若没带上可改用手动粘贴。
  2. 2选台：名单与现有 B 站监控台的 data/bot.db 同步，按监控台分组折叠展示；底部可直接填房间号、主播 UID 或直播间链接临时加入（不在名单也能看；纯数字会自动判断是房间号还是主播 UID）。点同一行的「听」或底部「只听」，只收该房间弹幕、不上舞台也不拉视频流。
  3. 3管理：每行悬浮出「＋/－ 舞台、设置分组、移除」；分组会写回监控台的 subject.grp，只有名单里的房间可改。
  4. 4布局：AUTO 自动铺排，或强制 4 / 6 / 9 / 16 宫格；双击画面单路查看，Esc 返回。
  5. 5弹幕：默认合并全部直播间；右上角下拉选单个房间，或点击画面标题栏的名称只看那一路。礼物 / SC 会以不同样式标记。
  6. 6画面：鼠标移到某一格，底部出现该路画质与音量；画质按 B 站档位重取流（原画需要登录态），音量逐格独立。
  7. 11重点观察：任意格子上悬停后点标题栏右侧的 ▣，可以依次把这一路放大到 2×2 → 3×3 → 还原，用一个大画面重点盯某一路；其它路会按顺序补进剩下的格子，放不下的显示「还有 N 路未上屏」。排布至少选「4」（2×2）或「9」（3×3）才有放大空间，拖标题栏换位、双击单路视图照常可用。放大只在当前页面记着，房间重新上舞台或刷新页面都会回到 1×1。
  8. 10播放模式：舞台右上角可切「流畅优先 / 低延迟」。默认流畅优先（缓冲约 4 秒、不裁剪已缓冲的数据，高码率 60fps 房间更稳，每 20 分钟自动软重连回收内存）；低延迟缓冲约 2.5 秒，网络很好、追求更贴近直播时用。
  9. 12后台：舞台头上的「后台暂停」控制窗口最小化 / 切到别的标签页时要不要继续播。默认暂停（省内存，弹幕照收，切回来每 0.1 秒逐个自动恢复）；要挂机盯盘就切「后台续播」，那会一直解码，内存和 CPU 占用更高。
  10. 7发送：底部选择目标房间，Ctrl+Enter 发送；单房间 3 秒限一条，B 站自己的风控仍然生效。
  11. 8速度：顶栏「下行」是全部直播流的总速度，鼠标悬停可看每一路的速度。
  12. 9内存：顶栏「内存」是浏览器当前占用，超过 1.2 GB 变橙；点一下会重建全部播放器立即释放（画面重连一次），长时间挂机建议定期点一下。
画面黑屏 / 弹验证码？B 站的嵌入页偶尔会要求人机验证，或拦掉静音自动播放。点格子右侧的 ↻ 重载一次，或点 ↗ 在浏览器里正常打开这一路；弹幕通道不受画面影响，仍然在收。
只听弹幕：不必把直播间放进舞台。左栏非舞台房间点 听（或底部填房间号后点「只听」），它会保持弹幕连接并出现在弹幕流下拉的「只听弹幕」分组里；不占舞台格子、不拉视频流。最多 16 路，再点一次「听」停止。
弹幕桥：顶栏右侧的「引擎」显示已连通的路数。它借用本机 Edge 的浏览器环境（B 站会按 TLS 指纹拦纯 Python 客户端），因此本工具需要在有 Edge 的 Windows 上、用你自己的终端启动；断开时会自动退避重连。

只作用于本程序发出的 HTTP(S) 请求（B 站接口、更新检查）。浏览器里的直播画面与弹幕、QQ 收消息的 WebSocket 不走这里。
「不使用代理」会强制清掉代理变量，系统里设了也不用；「使用系统代理」原样沿用 HTTP_PROXY / HTTPS_PROXY；「自定义代理」只支持 http:// / https://。保存后监控室立即换用新连接，采集 / 推送会在几秒内自动重启换用新配置——不用再手动重启。
