DD全能工作间

版本—·MIT 许可

在本机常驻，盯着你关注的 B 站主播：开播、下播、发动态，画成卡片图，通过你自己的 QQ 机器人推给你。附监控台与监控室两个界面。

  • 数据只在本机库在 data/，日志在 logs/，导出物在 out/；凭据只写 config/*.env，不入库、不上传。
  • 只监听环回两个服务都只绑定 127.0.0.1，不对局域网或公网开放。
  • 非官方工具与哔哩哔哩、腾讯无任何关联；不做风控绕过，不用于商业分发。

网络代理

读配置中…

只作用于本程序发出的 HTTP(S) 请求（B 站接口、卡片图、更新检查）。浏览器里的直播画面与弹幕、QQ 收消息的 WebSocket 不走这里。
「不使用代理」会强制清掉代理变量，系统里设了也不用；「使用系统代理」原样沿用 HTTP_PROXY / HTTPS_PROXY；「自定义代理」只支持 http:// / https://。保存后本进程立即换用，采集 / 推送会在几秒内自动重启换用新配置，监控室自己重建连接池——都不用再去「进程」页手动重启。

接入指引

装完就能打开这一页，不用改文件、不用重装。下面四件事都在页面里点完； 绑好之后，采集进程（取数）和推送进程（发 QQ）会自己起来。

  1. 1绑定 B 站账号检查中
    采集要用你自己的登录态：概览页「B 站登录态」→「扫码登录」，手机 B 站 App 扫一下即可。
  2. 2接入 QQ 机器人检查中
    推送要用你自己的机器人：机器人页填 AppID / AppSecret，再让目标 QQ 私聊机器人一句话，点「抓取推送目标」。
  3. 3确认监控名单可选
    默认是示例名单：在「监控名单」页按 UID 或主播名添加要盯的人；新加入的号下一轮只建基线，不推历史动态。
  4. 4采集 / 推送进程检查中
    两者都由监控台主进程托管：绑上账号自动开，没绑就保持关闭——页面服务不会被它们拖住。
